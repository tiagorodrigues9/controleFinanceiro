# Orçamentos

O recurso de Orçamentos é uma ferramenta de planejamento financeiro para ajudar a limitar seus gastos e economizar dinheiro.

---

## Como Funciona

1. **Definição de Limites**: Para cada mês, você pode definir um limite de gastos.
2. **Global ou Categórico**:
    - **Orçamento Global**: Você define um limite total para o mês, abrangendo todas as suas despesas.
    - **Orçamento por Categoria (Grupo)**: Você define limites específicos por categoria. Exemplo: R$ 800 para "Alimentação", R$ 300 para "Lazer".
3. **Acompanhamento Visual**: No dashboard de Orçamentos, barras de progresso mostram o quanto de cada limite já foi consumido naquele mês pelas suas Contas e Gastos.
4. **Alertas**: (Em desenvolvimento) Notificações quando o limite de uma categoria está próximo de ser estourado (ex: 80% do uso).

---

## Tipos de Despesas Contabilizadas

O sistema contabiliza tanto as **Contas a Pagar** (pagas ou a pagar no mês) quanto os **Gastos Diários** vinculados àquelas categorias, oferecendo um panorama em tempo real da aderência do seu consumo ao planejamento.
